Day 01: Working with HTML Lists

Lists organize information into clear, scannable structures.

1. Unordered List (<ul>) - Bullet Points

Unordered lists are used when the order of elements does not matter.

Key Frontend Technologies to Learn:

  • HTML5 (HyperText Markup Language - Page Structure)
  • CSS3 (Cascading Style Sheets - Styling & Layouts)
  • JavaScript ES6+ (Interactivity & Client Logic)
  • React.js (Frontend UI Component Framework)

2. Ordered List (<ol>) - Numbered Sequences

Ordered lists are used when the sequence of items is important (e.g., steps or rankings).

3. Nested Lists (Hierarchy)

Lists can be nested inside other list items to build hierarchical multi-level menus or breakdowns.

4. Description List (<dl>, <dt>, <dd>)

Description lists pair terms (<dt>) with their definitions (<dd>). Ideal for glossaries or key-value data.
