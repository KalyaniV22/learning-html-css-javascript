3. Inline Text Formatting Tags

1. Strong Importance (<strong>): This text is strongly important. (Used for important warnings or key concepts)

2. Stylistic Bold (<b>): This text is bold without extra semantic importance.

3. Emphasized Text (<em>): This text is emphasized for verbal stress.

4. Idiomatic / Italic (<i>): This text is italicized (e.g., technical terms, foreign words).

5. Highlighted Text (<mark>): This text is highlighted using the mark tag.

6. Small Print (<small>): This is small text used for disclaimers, copyright notes, or side comments.

7. Subscript (<sub>): Chemical formula for water is H2O, and Glucose is C6H12O6.

8. Superscript (<sup>): Mathematical equation: E = mc2, and 52 = 25.

9. Strikethrough (<del>) & Insertion (<ins>): Original Price: $100 | Special Discount Price: $75.

10. Abbreviations (<abbr>): HTML and MERN stack.

4. Code Formatting and Quotations

Inline Code snippet (<code>): Use the System.out.println("Hello World"); method in Java, or console.log() in JavaScript.

Preformatted Block (<pre>): Preserves both whitespace, indents, and new lines exactly as typed in source code:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("AD TECH Learning Program - Day 01");
    }
}

Blockquote (<blockquote>): Used for multi-line quotes from an external source:

"Semantic HTML is the foundation of accessible and SEO-friendly web development. It ensures that web content is meaningful to both humans and machines."
