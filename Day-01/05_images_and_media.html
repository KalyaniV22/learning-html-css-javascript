Day 01: Working with Images and Visual Media in HTML

Images make web pages visually engaging, informative, and interactive.

1. Basic Image Tag (<img>) & Accessibility (alt)

The <img> element is self-closing and requires two primary attributes: src (image file path or URL) and alt (alternate descriptive text).

Example A: HTML5 Technology Icon

Why the alt attribute is MANDATORY:
1. Accessibility (a11y): Screen readers read the alt text aloud for visually impaired users.
2. Fallback: Displays when network connections fail or the image URL is broken.
3. SEO: Search engine crawlers index alt text to understand image content.

3. Semantic Figure and Caption (<figure> & <figcaption>)

The <figure> element wraps self-contained content (like diagrams, illustrations, or photos), and <figcaption> adds a visible caption directly associated with it.

4. Image as a Hyperlink

Nesting an <img> tag inside an <a> tag transforms the image into a clickable button link.
