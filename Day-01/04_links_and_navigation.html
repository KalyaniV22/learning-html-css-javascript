4. Bookmark Anchor Section Target

This section has an id="bookmark-section" attribute. When a user clicks a link with href="#bookmark-section", the browser smoothly jumps down to this exact position on the page.

This feature is commonly used for long web pages, single-page navigation bars, and "Back to Top" links.
