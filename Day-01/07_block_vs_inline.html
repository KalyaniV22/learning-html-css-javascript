Day 01: Block-level vs Inline-level Elements

Every HTML element has a default display behavior: either Block or Inline.

1. Block-Level Elements (<div>, <p>, <h1>, <ul>)

Characteristics of Block-level Elements:
• Always start on a new line in the document flow.
• Automatically expand to take up 100% of the available width of their parent container.
• Can contain both other block elements and inline elements.

Common Block-level Examples:

This paragraph is inside a block-level <div> element.

This is a separate block-level <div> element. Notice how it starts on a brand new line!

List of Core Block-Level Tags:

  • <div> - Generic block container
  • <p> - Paragraph text block
  • <h1> to <h6> - Heading blocks
  • <ul>, <ol>, <li> - List structures
  • <form>, <table> - Form and Table wrappers
  • <header>, <main>, <section>, <footer> - HTML5 Semantic containers

2. Inline-Level Elements (<span>, <a>, <b>, <img>)

Characteristics of Inline-level Elements:
• Do NOT start on a new line. They sit side-by-side on the same line as surrounding text.
• Take up only as much width as their content requires.
• Should generally contain only text or other inline elements (NOT block elements).

Common Inline-level Examples:

In this sentence, this text is wrapped inside a <span> tag, followed by a hyperlink (<a>), and some bold text (<strong>), plus a highlighted word (<mark>). All of these elements stay together on the exact same line!

List of Core Inline-Level Tags:

  • <span> - Generic inline container
  • <a> - Hyperlink anchor
  • <strong>, <b> - Bold / important text
  • <em>, <i> - Italic / emphasis text
  • <mark> - Highlighted text
  • <code> - Monospaced code text
  • <img> - Inline image element

3. Side-by-Side Summary Matrix

Property Block-Level Elements Inline-Level Elements
New Line? Yes, starts on a new line. No, stays on the same line.
Width Occupied 100% parent container width. Only as wide as content inside.
Generic Container Tag <div> <span>
