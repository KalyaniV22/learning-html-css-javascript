Welcome to Day 01: HTML Document Structure

1. Understanding the HTML Skeleton

HTML (HyperText Markup Language) uses tags to define elements on a web page. Every standard HTML5 page requires a specific structure starting with the <!DOCTYPE html> declaration.

2. Key Structural Components

  • <!DOCTYPE html>: Tells the web browser that this document is written in standard HTML5.
  • <html lang="en">: The root element of the entire webpage. The lang="en" attribute defines English as the primary language.
  • <head>: Contains hidden metadata, character set configurations, external links, and the browser tab title.
  • <body>: Contains all user-visible page elements like text, images, links, tables, and buttons.

3. HTML Comments Demonstration

Comments in HTML start with <!-- and end with -->. Browsers completely ignore comments during rendering, making them perfect for developer documentation.
