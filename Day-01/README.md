# Day 01 - HTML Basics & Semantic Web Structure

Welcome to **Day 01** of the MERN Foundation Learning Program at **AD TECH Enterprises Pvt. Ltd.**

Today's focus is building a rock-solid understanding of **HyperText Markup Language (HTML)**—the fundamental backbone of all web pages.

---

## 🎯 Learning Objectives

By completing Day 01, you will understand and master:
1. What HTML is, how web browsers parse HTML documents, and standard HTML syntax.
2. The standard structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
3. Core HTML metadata tags (`<meta charset="UTF-8">`, `<meta name="viewport">`, `<title>`).
4. Headings (`<h1>` to `<h6>`) and paragraph text (`<p>`).
5. Semantic text formatting tags (`<strong>`, `<em>`, `<mark>`, `<code>`, `<pre>`, `<sub>`, `<sup>`, `<del>`, `<ins>`, `<blockquote>`).
6. Unordered (`<ul>`), Ordered (`<ol>`), and Description (`<dl>`) lists.
7. Hyperlinks (`<a>`), relative vs absolute paths, opening links in new tabs (`target="_blank"`), and page section anchors (`#id`).
8. Working with images (`<img>`), alt attributes for accessibility, dimensions, and `<figure>` with `<figcaption>`.
9. Building tabular data with `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<th>`, `<td>`, `colspan`, and `rowspan`.
10. Understanding the fundamental difference between **Block-level** (`<div>`, `<p>`, `<h1>`) and **Inline-level** (`<span>`, `<a>`, `<b>`) elements.
11. Structuring modern web layouts using **HTML5 Semantic Elements** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
12. Applying all Day-01 skills to create a **Pure HTML Personal Portfolio & Resume Mini Project**.

## 💡 Key Takeaway & Golden Rules
- **HTML is for Structure, not Styling:** HTML provides the meaning and semantics of content. Styling belongs to CSS (Day 3 & 4).
- **Always Close Your Tags:** Ensure opening tags `<tag>` have corresponding closing tags `</tag>` (except self-closing tags like `<img>`, `<br>`, `<hr>`, `<meta>`).
- **Use Meaningful Alt Text:** Always provide descriptive `alt` attributes on images for web accessibility (screen readers) and fallback display.
- **Prefer Semantic HTML:** Use `<article>`, `<section>`, `<header>`, and `<nav>` instead of generic `<div>` tags whenever possible for better SEO and accessibility.
