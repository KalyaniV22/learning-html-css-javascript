# Day 04 - CSS Grid, Responsive Design & Animations

Welcome to **Day 04** of the MERN Foundation Learning Program at **AD TECH Enterprises Pvt. Ltd.**

Today's module covers **CSS Grid Layouts**, **Mobile-First Responsive Web Design**, **Media Queries**, **CSS Transitions**, and **Keyframe Animations**.

---

## 🎯 Learning Objectives

By completing Day 04, you will master:
1. CSS Grid Container properties (`display: grid`, `grid-template-columns`, `grid-template-rows`, `gap`).
2. The Fractional Unit (`fr`), `repeat()`, `auto-fit`, `auto-fill`, and `minmax()` fluid sizing functions.
3. Grid Area Layouts (`grid-template-areas`, `grid-area`, `grid-column`, `grid-row`).
4. Mobile-First Responsive Design principles and Breakpoints using `@media (max-width / min-width)`.
5. Fluid typography (`clamp()`) and responsive media scaling.
6. CSS Transitions (`transition-property`, `duration`, `timing-function`, `delay`).
7. 2D/3D Transforms (`transform: translate, scale, rotate, skew`).
8. CSS Keyframe Animations (`@keyframes`, `animation-name`, `animation-duration`, `animation-iteration-count`).
9. CSS Variables Theme Toggling (Light / Dark Mode).
10. Building a modern, animated **AD TECH Product Landing Page Mini Project**.
