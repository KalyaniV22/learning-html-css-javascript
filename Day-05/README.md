# Day 05 - JavaScript Fundamentals, Logic & Control Flow

Welcome to **Day 05** of the MERN Foundation Learning Program at **AD TECH Enterprises Pvt. Ltd.**

Today's module transitions into **JavaScript (ES6+)** programming—the core logic engine of the web and the MERN stack (Node.js, Express.js, React.js).

---

## 🎯 Learning Objectives

By completing Day 05, you will master:
1. JavaScript Role in MERN, Execution Context, and Browser Console logging (`console.log`).
2. Variable declarations: `let` (block-scoped), `const` (immutable reference), `var` (function-scoped).
3. Data Types: Primitives (`String`, `Number`, `Boolean`, `Null`, `Undefined`, `Symbol`, `BigInt`) & References (`Object`, `Array`, `Function`).
4. Operators & Expressions: Arithmetic, Assignment, Comparison (`===` strict equality vs `==`), Logical (`&&`, `||`, `!`), and Ternary operator (`condition ? a : b`).
5. Control Flow & Conditionals: `if`, `else if`, `else`, `switch`, and Truthy / Falsy values.
6. Loops & Iteration: `for`, `while`, `do...while`, `for...of` (array iteration), `for...in` (object iteration).
7. Functions & Arrow Syntax: Function Declarations, Function Expressions, Arrow Functions (`const fn = () => {}`), Return values, Default & Rest parameters.
8. Arrays & Modern Methods: `push`, `pop`, `shift`, `unshift`, `slice`, `splice`, `indexOf`, `includes`, `map`, `filter`, `reduce`, `find`, `forEach`.
9. Objects & Methods: Object literals, Dot vs Bracket notation, Nested objects, Object methods, `Object.keys()`, `Object.values()`, Object destructuring.
10. Building an interactive **JavaScript Developer Knowledge Quiz App Mini Project**.
