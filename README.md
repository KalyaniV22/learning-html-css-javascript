## 📌 Project Overview

This repository tracks the complete 12-day learning journey for mastering modern web development fundamentals (HTML, CSS, and JavaScript) to transition from backend Java/Spring Boot development into the MERN (MongoDB, Express.js, React.js, Node.js) tech stack.

The goal is to practice writing clean, semantic, and maintainable frontend code from scratch by completing daily tutorials, exercises, minor projects, and a final capstone AI Chatbot project.

## 🚀 How to Run the Projects Locally

   ```bash
   git clone https://github.com/KalyaniV22/learning-html-css-javascript.git
   cd learning-html-css-javascript
   ```

2. **Open Exercises & Projects:**
   - Double-click any `.html` file inside `Day-01/`, `Day-02/`, `Day-03/`, `Day-04/`, or `Day-05/` to open it in your browser.
