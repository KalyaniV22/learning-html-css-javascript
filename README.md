# Day 03 — CSS Flexbox Practice

**Topic:** CSS Flexbox
**Program:** AD TECH MERN Foundation Learning Program (Task-02)

## What I practiced today
- `display: flex` and turning a container into a flex context
- `flex-direction` (row, row-reverse, column, column-reverse)
- `justify-content` (main-axis alignment)
- `align-items` (cross-axis alignment)
- `flex-wrap` (wrapping items onto new lines)
- `flex-grow`, `flex-shrink`, `flex-basis` (controlling item sizing)
- `order` (changing visual order independent of HTML order)

## Files in this folder
- `01-flex-direction.html` — practice with all 4 flex-direction values
- `02-justify-content.html` — practice with all justify-content values
- `03-align-items.html` — practice with all align-items values
- `04-flex-wrap-and-sizing.html` — flex-wrap, grow/shrink/basis, and order
- `notes.md` — written notes/summary of concepts learned

## How to view
Open any `.html` file directly in a browser. Try resizing the browser window
on `04-flex-wrap-and-sizing.html` to see the wrap and shrink behavior live.
