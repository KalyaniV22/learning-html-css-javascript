Day 02: Native HTML5 Multimedia (<video> & <audio>)

HTML5 allows playing audio and video directly in web browsers without plugins.

1. Native HTML5 Video Player (<video>)

The <video> tag supports attributes like controls (show play/pause UI), poster (cover thumbnail image), preload="metadata", and width/height.

2. Native HTML5 Audio Player (<audio>)

The <audio> tag provides a compact, accessible media player for sound clips and podcasts.

3. HTML5 Multimedia Attributes Summary

Attribute Elements Description / Function
controls <video>, <audio> Displays default play, pause, volume, and timeline controls.
poster <video> Specifies an image URL to be shown while the video is downloading or until played.
autoplay <video>, <audio> Automatically starts media playback upon page load (often blocked unless muted).
muted <video>, <audio> Sets default audio volume output to zero (silent).
loop <video>, <audio> Replays the media file automatically every time it finishes.
