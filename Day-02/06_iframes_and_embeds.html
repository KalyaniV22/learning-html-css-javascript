Day 02: Embedding Web Documents with Iframes (<iframe>)

An inline frame (iframe) embeds an external HTML web page directly inside your current page canvas.

1. Basic Inline Frame (External Web Document)

Always include a descriptive title attribute on every iframe for screen reader accessibility!

2. Inline HTML Content Frame (<iframe srcdoc="...">)

The srcdoc attribute allows rendering inline HTML markup directly inside an isolated iframe box.

3. Security Sandboxing (<iframe sandbox="...">)

The sandbox attribute applies strict security restrictions to embedded content (e.g., blocking scripts, forms, or top-level navigation).

Sandbox Value Security Restriction Lifted / Allowed
sandbox="" Applies MAXIMUM security (blocks scripts, forms, popups, and same-origin cookies).
sandbox="allow-scripts" Allows executing client JavaScript inside the iframe.
sandbox="allow-forms" Allows submitting forms from within the iframe.
sandbox="allow-same-origin" Allows content to retain its original domain origin context.
