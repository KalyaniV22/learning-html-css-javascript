# Day 03 - CSS Basics, Box Model & Flexbox Layouts

Welcome to **Day 03** of the MERN Foundation Learning Program at **AD TECH Enterprises Pvt. Ltd.**

Today's module covers **Cascading Style Sheets (CSS)** fundamentals, including CSS Selectors, Colors, Typography, the CSS Box Model, Positioning, and mastering the **Flexbox Layout System**.

---

## 🎯 Learning Objectives

By completing Day 03, you will master:
1. CSS Syntax, Inline vs Embedded vs External Style Sheets (`<link rel="stylesheet">`).
2. CSS Selectors (Element, Class `.class`, ID `#id`, Grouping, Descendant, Pseudo-classes `:hover`, `:focus`, `:nth-child`).
3. CSS Color Systems (HEX, RGB, HSL, RGBA, CSS Custom Variables `var(--color)`).
4. The CSS **Box Model** (Content, Padding, Border, Margin, and `box-sizing: border-box`).
5. CSS Positioning (`static`, `relative`, `absolute`, `fixed`, `sticky`, `z-index`).
6. Display properties (`inline`, `block`, `inline-block`, `flex`, `none`).
7. **Flex Container Properties:** `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content`, `gap`.
8. **Flex Item Properties:** `flex-grow`, `flex-shrink`, `flex-basis`, `flex`, `align-self`, `order`.
9. Building responsive navigation bars, hero headers, and card grids using pure Flexbox.
10. Applying Day-03 CSS & Flexbox to build the **Glassmorphism Styled Personal Portfolio Mini Project**.
